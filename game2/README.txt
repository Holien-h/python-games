GAME 2: HANGMAN

ABOUT
Guess the hidden word one letter at a time. The game randomly chooses a
programming and technology-related word from a built-in list.

HOW TO PLAY
1. Open a terminal in this folder.
2. Run the game with Python:

       python game2.py

3. Enter one letter when prompted. Guesses are case-insensitive.
4. Correct guesses reveal each matching letter in the word. Incorrect guesses
   cost one life. You start with six lives.
5. Guess all the letters before you run out of lives to win.

INPUT RULES
- Enter one alphabetic letter at a time.
- Invalid input and letters you have already guessed do not cost a life.

REQUIREMENTS
Python 3. No additional packages are needed.
