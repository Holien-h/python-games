GAME 1: ROCK, PAPER, SCISSORS, LIZARD, SPOCK

ABOUT
This is a command-line game where you play the computer using the five-choice
Rock, Paper, Scissors, Lizard, Spock rules. The first player to win three
rounds wins the game. A draw does not award a point.

HOW TO PLAY
1. Open a terminal in this folder.
2. Run the game with Python:

       python game1.py

3. Enter one of: rock, paper, scissors, lizard, or spock. Entries are
   case-insensitive.
4. The computer randomly selects a choice. The round result and scores are
   displayed after each choice.

RULES
- Rock beats scissors and lizard.
- Paper beats rock and Spock.
- Scissors beats paper and lizard.
- Lizard beats Spock and paper.
- Spock beats scissors and rock.

REQUIREMENTS
Python 3. No additional packages are needed.
